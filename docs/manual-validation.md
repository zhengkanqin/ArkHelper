# 手工验收清单

自动测试使用隔离宿主和模拟采集，不能代替真实战斗验收。运行完整集成测试前关闭游戏和助手，避免真实 IPC 与测试宿主冲突。

## 首次使用与连接

- [ ] 新目录或未确认的旧配置显示风险说明，默认不勾选。
- [ ] 阅读未超过 10 秒、未勾选时无法确认；未完成阅读时切走窗口需重新计时。
- [ ] 关闭/不同意直接退出，不启动游戏、不连接采集；确认保存失败不放行。
- [ ] 成功确认后重启不重复提示，原配置保留。
- [ ] 安装后台组件后，自动启动与连接不重复请求管理员授权。
- [ ] 已有游戏只连接；连接失败或切换分辨率/全屏不关闭、重启游戏。
- [ ] 启动器不出现命令行窗口，快捷方式有图标。

## 显示与交互

- [ ] 未进关时数据面板隐藏；进关显示，战后保留并可关闭，下一关更新。
- [ ] 画面标记只在战斗且游戏前台时显示，支持全屏、分辨率和窗口尺寸变化。
- [ ] 暂停过滤在下一次界面刷新响应。
- [ ] 菜单滚轮只滚动，不改滑杆或开关；拖动开关外取消点击。
- [ ] 设置位于菜单内；菜单边缘可调高度，长内容可滚动。
- [ ] 功能隐藏即停用；显示顺序、外观、位置、面板磁吸及收纳宽度重启后保留。
- [ ] 隐藏的磁吸成员不会在调宽时闪现；内容截断时悬停显示完整内容。

## 战斗统计与单位信息

- [ ] 伤害、治疗、承伤和有效回费与战斗表现一致，表格列对齐、优先紧凑布局、合计不重复。
- [ ] 回费只计实际到账，自然恢复、满费溢出和撤退返还不计入。
- [ ] 普通点击统计正文不打开设置，标题栏齿轮可进入配置。
- [ ] 我方数值按实例显示；最多六类，可调整顺序、悬停、暂停、字体、偏移与透明度。
- [ ] 敌方数值只显示悬停范围内最近一个存活敌人；未获得的属性显示“—”。
- [ ] 血量与位置在移动、暂停/恢复和倍速切换时正常，偏移、悬停和透明度配置生效。
- [ ] 攻击范围在适用远程敌人旁显示，补帧、暂停过滤、线宽与虚实配置生效。
- [ ] 路径从当前剩余段开始，多个悬停目标可同时触发；离开后画完再按残留时间消失。
- [ ] 路径点击触发、颜色、速度、透明度、残留时间与线型配置生效；传送段不连线。

## 整关资料与 PRTS

- [ ] 敌方数据与敌方 PRTS 独立开关，整关所有已读敌人类型可查，战后保留。
- [ ] 出怪列表保留整关已读波次、随机和条件分支；倒计时只显示可确认的时间。
- [ ] PRTS 文本无网页标签残留，表格和长文随宽度换行；缺头像会重试。
- [ ] 断网或解析失败能结束加载并重试，不无限等待。
- [ ] 已缓存内容可离线使用；过期更新失败可标记使用旧内容。
- [ ] 缓存路径打开/切换和上限调整生效，缩容后台清理，未预下载整站数据。

## 模式与稳定性

- [ ] 普通关、肉鸽：同关重开或进入新关清理旧实例与属性，不用参考资料替代局内值。
- [ ] 卫戍协议：连续多轮正常累计，同角色多个在场时头顶数值分开、表格按角色合计。
- [ ] 卫戍的敌方 PRTS、出怪列表等特殊信息允许不可用；不显示伪造结果。
- [ ] 生息演算及动态地图：未知字段明确降级；不沿用上一关路径或属性。
- [ ] 退出、重进关、助手重启和多次启停后无旧数值串场、明显卡顿或崩溃。
